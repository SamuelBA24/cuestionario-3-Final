# Herramientas para diagramar

## Usar: draw.io / diagrams.net

- Enlace: [https://app.diagrams.net](https://app.diagrams.net)
- Activar librerías **UML**, **BPMN 2.0** y **ArchiMate** (*More shapes*).
- Exportar PNG o PDF; guardar también el `.drawio`.

## Alternativas

| Herramienta | Uso |
|-------------|-----|
| **Mermaid** | Diagramas como código (secuencia, flujo); se renderiza en GitHub |
| **PlantUML** | UML / C4 como código |
| **Archi** | Modelado ArchiMate de escritorio |
| Lucidchart, Excalidraw, Miro | Colaboración en empresas |

## Por notación

| Notación | Usar |
|----------|------|
| BPMN | draw.io (BPMN 2.0) |
| UML | draw.io o Mermaid / PlantUML |
| ArchiMate | draw.io (shapes ArchiMate) o Archi |
